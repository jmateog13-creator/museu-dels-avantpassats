# Museu dels Avantpassats

Museu virtual per a 1r d'ESO: 21 vitrines, una per instrument de l'orquestra. Cada vitrina rebobina la història de l'instrument fins als seus avantpassats, amb animació i so sintetitzat. El doctor Martí i la doctora Carla et fan preguntes per recuperar l'arxiu del museu.
